## Decisiones de la versión 0.1 · 12/11/2026

| Decisión | Justificación | Cuándo revisarla |
|---|---|---|
| Catálogo común y fuentes seleccionadas por caso | Facilita reutilización sin imponer una fuente universal | Cuando una pregunta no encuentre cobertura |
| Seis candidatas en el catálogo inicial | Evita una búsqueda indefinida | Al cerrar el primer módulo o ante una carencia bloqueante |
| Pez león como primer caso | Conecta datos disponibles y experiencia del autor | Al probar generalización |
| NAS como una entrada del piloto | Aporta observaciones, pero no cubre todos los problemas | Si cambian pregunta, taxón o territorio |
| No imponer región antes del diagnóstico | Permite conocer la cobertura disponible | Antes de un diagnóstico territorial o comercial específico |
| No integrar Barbados todavía | Es un ejemplo de conjunto específico, no una prioridad del proyecto | Cuando responda una pregunta necesaria |
| No estimar rentabilidad | No hay costes ni evidencia comercial suficiente | Al disponer de datos adecuados |
| No desarrollar predicción en la primera versión | Prioridad a resultados descriptivos y reproducibles | Tras cerrar y validar la entrega inicial |
| Publicar avances con estado explícito | Distingue resultados de hipótesis y tareas pendientes | En cada actualización |
